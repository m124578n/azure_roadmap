# Corrections — W20: What is Azure? A Beginner's Map

## Recurring Patterns to Watch

**1. 動詞時態：have been + V-ing**
- 錯：`I've been used Azure`
- 對：`I've been using Azure`
- 規則：現在完成進行式是 have/has been + 動詞ing，不是 have been + 過去式

**2. make / let 的用法**
- 錯：`It makes even one person can build`
- 對：`It means even a single person can build` 或 `It lets even a single person build`
- 規則：make + 人 + 原形動詞（不加 can）；或直接改用 "means" / "lets"

**3. staff vs stuff**
- 錯：`put all staff in`（意思變成「把所有員工放進去」）
- 對：`store it all`
- 記住：**staff = 員工 / stuff = 東西**（這是高頻錯誤）

## Vocabulary / Phrases Learned

| 你的用法 | 更自然的說法 | 說明 |
|---------|------------|------|
| by this time I decided | that's what pushed me to | 表達「這就是原因」的慣用說法 |
| the different is | differ in | different 是形容詞，這裡要動詞 differ |
| more high level | higher-level | 比較級的正確形式 |
| Image you are | Imagine you are | image 是名詞，imagine 才是動詞 |
| easily to build | easier to build | 比較級 + to + 動詞原形 |
