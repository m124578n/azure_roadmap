# Corrections — W20: What is Azure? A Beginner's Map

## Recurring Patterns to Watch

**1. 動詞時態：have been + V-ing**
- 錯：`I've been used Azure`
- 對：`I've been using Azure`
- 規則：現在完成進行式是 have/has been + 動詞ing，不是 have been + 過去式
- 延伸：`I've been working here for two years` / `She's been studying all day`

**2. make / let 的用法**
- 錯：`It makes even one person can build`
- 對：`It lets even a single person build` 或 `It means even a single person can build`
- 規則：
  - `make + 人 + 原形動詞`（不加 can）→ `It makes things easier`
  - `let + 人 + 原形動詞` → `It lets you build anything`
  - 想表達「代表」時用 `mean` → `It means you can build anything`

**3. staff vs stuff**
- 錯：`put all staff in`（變成「把員工關進去」）
- 對：`store it all` / `put everything in`
- 記住：**staff = 員工 / stuff = 東西**
- 這是台灣人高頻錯誤，以後每次要寫 stuff 先停下來確認

**4. 形容詞不能當動詞用**
- 錯：`the different is pricing`
- 對：`they differ in pricing` 或 `the difference is pricing`
- 規則：different（形容詞）不能當動詞，動詞是 differ；名詞是 difference

**5. 比較級的形成**
- 錯：`more high level` / `easily to build`
- 對：`higher-level` / `easier to build`
- 規則：
  - 短字（一、二音節）直接加 -er：high → higher、easy → easier
  - 長字才用 more：more expensive、more complicated
  - 比較級 + to + 原形動詞：easier to build（不是 easily to）

**6. 動詞拼字**
- `destory` → `destroy`
- `maintance` → `maintain`（動詞）/ `maintenance`（名詞）
- `Image` → `Imagine`（image 是名詞，imagine 是動詞）
- 建議：寫完草稿後用 spell check 掃一遍

## Vocabulary / Phrases Learned

| 你的用法 | 更自然的說法 | 說明 |
|---------|------------|------|
| by this time I decided | that's what pushed me to | 表達「這就是原因」，pushed me to 有「驅動力」的感覺 |
| the different is | differ in / the difference is | different 是形容詞，不能當動詞 |
| more high level | higher-level | 短字用 -er，不用 more |
| Image you are | Imagine you are | image 名詞，imagine 動詞 |
| easily to build | easier to build | 比較級 + to V |
| offical | official | 拼字，注意只有一個 f |
| envirment | environment | 拼字，中間有 on |
| destory | destroy | 拼字 |
| know whole the picture | understand the full picture | 語序：whole/full 放在名詞前 |
| in reality | physically | 表達「在現實中/實體的」，physically 更精準 |

## Sentence Patterns Worth Keeping

這篇有幾句寫得很好，值得記下來當模板：

```
That's what pushed me to [do something].
→ 表達「這就是讓我去做某事的原因」

You only pay for what you use.
→ 隨用隨付的標準說法，很乾淨

No [noun], no [noun] burning [doing something bad].
→ 排比句型，強調節省成本的感覺
例：No upfront hardware costs, no idle servers burning money at 3 a.m.
```
